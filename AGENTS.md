# Agent instructions

- For any task, if a critical-path issue or consequential decision arises, stop, explain the evidence, options, and consequences, and wait for my input before proceeding.
- Do not commit any changes unless I explicitly instruct you to commit. Permission to edit files, switch branches, or perform merge work is not permission to commit. Leave changes uncommitted otherwise.
- Do not launch or open Xcode unless it is absolutely necessary for a required task that cannot be completed with command-line or file tools. Use direct file edits and command-line builds and tests by default. Keep the project workspace closed during direct file edits to avoid Xcode's disk/editor version-conflict prompts. Do not launch Xcode merely to preview changes or perform optional verification.
