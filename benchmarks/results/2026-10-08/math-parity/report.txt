Edge-case differences:
1. Signed-zero equatorial direction (-1,0,-0): Mitsuba basis (0,0,-1),
   PolRAY basis (0,0,+1). This is a 180-degree axis reversal. One related
   world Jones result differs by a global minus sign; Mueller transport agrees.
   Gauge-aware world-Jones maximum absolute error remains 1.9431e-5.
2. Very near the critical angle, n=0.4, cosine=0.9165151, k=0 or 1e-8:
   Fresnel maximum amplitude component error 0.001218765. Tiny differences
   in the nearly-zero square-root argument are amplified here. The same
   imaginary signs are retained; this is not an observed conjugation error.
3. Normalization stress check uses Pollia's actual Jarecki normalization
   expression on arbitrary Jones matrices and PolRAY normalizeJonesToUnitM00.
   At amplitude scale 1e-20, Pollia's floor at M00=1e-30 prevents unit-M00
   normalization (relative output-amplitude discrepancy ~0.999986).
   At scale 1e20, Pollia's raw squared magnitudes overflow while PolRAY's
   power-of-two rescaling still returns a finite unit-M00 matrix.
   This is a numerical robustness gap, not a sign/sine mismatch. These scale
   checks do not establish the frequency of such inputs in rendered scenes.
4. Both production validity paths reject nonfinite Jarecki gamma; harness
   respects this. Zero-transport and retroreflection status cases agree.

Coverage limits:
Pollia executed scalar templates, not its Metal JIT rendering path. Projection
and storage checks use known layout expectations where PolRAY has no equivalent
Mitsuba spectrum adapter. Different camera/source conventions were reconciled
using the same physical input/output axes. NaN/overflow cases are not reported
as ordinary-input numerical agreement. No claim of exhaustive equivalence.

No fixes or commits made. Per AGENTS.md, normalization behavior requires user
