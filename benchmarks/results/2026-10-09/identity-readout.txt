First-hit identity shortcut experiment — 2026-10-09

Baseline commit: 417b66f2e9e4c5bc789bd4f4c67588efbeff5603
Shortcut removed from both engines after user approval. Production sources match the
committed baseline. The experimental code is preserved in identity-shortcut.patch.

Recommendation: do not retain this implementation as a performance optimization.
Both engines were slower with the shortcut in every tested block and workload.

Environment: Apple M4 Max, MacBook Pro Mac16,6, 128 GB, AC power.
Backend: Dr.Jit Metal, metal_rgb_polarized, default JIT flags.
Scene: full RGB Cornell nylon materials; white/green/red40; red3 remains unused.
Protocol: four blocks, twelve timed renders per configuration per block, three warmups.
Configuration order rotates within each block and reverses in alternating blocks.
Each four-way iteration uses the same seed. Timings synchronize GPU completion.
Reported time: median of four block medians; compilation, host readback, display excluded.
Russian roulette depth 100 for timing cases.

Correctness:
RGB: 48 seeded off/on comparisons passed; max absolute pixel difference 1.90734863e-06.

Checks cover directly visible polarized emission, direct lighting, multiple bounces,
depolarization, channel-divergent histories (RGB), and Russian roulette.
Outputs are numerically equivalent within the rounding tolerance, not bit-identical.
Existing rendering/worker regression suite: all 8 tests passed after the experiment.
Source whitespace check: git diff --check passed.

Implementation:
Mueller skips initial identity applications to source Stokes vectors and the first
identity x surface Mueller product. PIS skips initial identity Jones state applications
and the first identity x surface Jones product. Both use Dr.Jit conditional control flow.

Kernel evidence (RGB nylon depth4 main JIT kernel operation counts):
Mueller: 4046 off -> 5015 on; PIS: 4498 off -> 5507 on.
Extra conditional control flow/intermediates enlarge the generated graph. This is
consistent with the timing regression; operation counts alone do not isolate its cause.

Scope: evidence applies to this conditional implementation on this Metal/Dr.Jit setup.
These are equal-SPP timings, not an equal-error comparison between the two estimators.
Raw per-render times, per-block medians, kernel records, and source hashes are in identity-rgb.json.
